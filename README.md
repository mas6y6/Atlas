# Atlas

Atlas is a self-hosted server and process management platform designed to make deploying and managing applications across multiple nodes simple, secure, and accessible.

## Goals

- **Easy to use:** Simplify deployment and management across multiple servers.
- **Secure by design:** Protect master-to-node communications with cryptographic keys and encrypted connections, minimizing unnecessary network exposure.
- **Multi-node management:** Manage processes and applications across multiple machines from a centralized interface.
- **Application-agnostic:** Support Minecraft servers and other applications that can run as managed processes.
- **Extensible API:** Provide an API for developers to build integrations, automation, and third-party tools on top of Atlas.

## Project Status

Atlas is currently in early development. Features, architecture, and APIs are subject to change.

## Security

Security is a core design goal of Atlas. Communication between the master and nodes is intended to use authenticated, encrypted connections, with strict authorization and minimal exposure of node services.
